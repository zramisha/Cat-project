

# Cat Adoption Website

This project is a web application developed for the CSE470 : Software Development course at BRACU, implementing a platform for cat adoption using the MERN stack (MongoDB, Express.js, React.js, Node.js). The project follows the MVC architecture and Agile methodology with Scrum for development.

## Project Overview

The Cat Adoption Website allows users to explore, wishlist, and request to buy cats. The platform features detailed listings of cats with information such as breed, age, description, and shelter location. Shelters can post cats for adoption, and users can find and explore shelter locations with Google Maps integration. Additionally, the platform includes an event feature for various activities related to cat adoption.

## Features

### General User Features

- **Explore Cats**: Users can browse through cat listings with pictures, breed, age, description, and shelter information.
- **Wishlist**: Users can add cats to their wishlist for future reference.
- **Request to Buy**: Users can request to buy cats directly from the listings.

### Shelter User Features

- **Post Cats for Adoption**: Shelter users can create posts for cats they want to put up for adoption.
- **Manage Shelter Information**: Shelters can update their descriptions and location details.

### Additional Features

- **Google Maps Integration**: View and locate shelters using Google Maps.
- **Event Management**: List and explore events related to cat adoption, such as meet-and-greets, adoption drives, etc.

## Project Structure

This project follows the MVC (Model-View-Controller) architecture:

- **Model**: Handles the database and business logic using MongoDB.
- **View**: The frontend interface built with React.js.
- **Controller**: Manages user input, processes requests, and updates the model and view accordingly.

## Development Process

The project is developed using Agile methodology with Scrum framework. The team works in sprints to incrementally develop and refine the application.

### Sprint Breakdown

- **Total Sprints**: 5
- **Sprint Duration**: 2 weeks each
- **Sprint Responsibilities**: Each team member takes turns as the sprint lead, responsible for collecting progress reports, managing tasks, and reporting issues.

## Technical Stack

- **Frontend**: React.js
- **Backend**: Express.js and Node.js
- **Database**: MongoDB
- **Other Tools**: Google Maps API for location integration

## Installation and Setup

1. Clone the repository:
    
    ```bash
    git clone https://github.com/zramisha/Cat-project.git
    cd Cat-project
    ```
    
2. Install dependencies:
    
    ```bash
    npm install
    ```
    
3. Run the application:
    
    ```bash
    npm i
    npm run dev
    ```
